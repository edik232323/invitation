# Приглашение на юбилей: Надира Мырзагулова, 50 лет

Сайт: https://edik232323.github.io/invitation/

- `index.html` — сам сайт (KG/RU, музыка, таймер, анкета).
- `fonts/` — шрифт Cormorant с кыргызскими буквами (ң, ө, ү).
- `og.jpg` — картинка для превью в WhatsApp (`og.html` — её исходник).
- `apps-script/Code.gs` — скрипт Google Таблицы для ответов гостей.

## Подключение анкеты (один раз, ~2 минуты)

1. Создайте новую Google Таблицу (sheets.new), назовите «Юбилей — ответы гостей».
2. В таблице: **Расширения → Apps Script**. Удалите всё в редакторе и вставьте код из `apps-script/Code.gs`. Нажмите 💾.
3. Вверху выберите функцию **setup** и нажмите **Выполнить**. Google попросит разрешения: выберите свой аккаунт → «Дополнительные настройки» → «Перейти на страницу проекта» → «Разрешить». На почту придёт тестовое письмо, в таблице появятся листы «Итог» и «Ответы».
4. **Начать развертывание → Новое развертывание** → тип «Веб-приложение»:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**

   Нажмите «Развернуть» и скопируйте URL веб-приложения (заканчивается на `/exec`).
5. Вставьте этот URL в `index.html` в строку `const RSVP_URL = "..."`.

## Кто получает письма

Владелец таблицы и все, у кого есть доступ к таблице на **редактирование**. Чтобы добавить человека, нажмите «Настройки доступа» в таблице и добавьте его как редактора. Сколько человек придёт, видно на листе «Итог».
